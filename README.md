# 灵盘（Linpo）

Linpo 是位于 OpenClaw 与人之间的人机协作编排交互层。
Linpo v0.7 主界面收敛为 `kanban + toolbar`：
- 一句话描述需求，生成并编辑流程图
- 流程图解析为可并行任务队列，在看板中调度
- 敏感操作统一审批，任务产出可预览并可通过输入框调试

ravin 测试服务域名：`linpo.duckdns.org`
