# SoulBoard（灵板）

SoulBoard 是一个从小功能闭环起步、逐步成长的平台型项目。

当前第一阶段的产品起点是：

> **围绕单一命题组织多个 OpenClaw 实例进行结构化辩论，由用户作为主持人/裁判介入，并生成可复盘总结。**

当前仓库已完成一次项目级重置：旧版 roboard 的实现、设计与配置已迁出当前仓库根目录，仅作为仓库外本地归档参考，不再作为当前项目的权威来源。

- 先定文档，再做实现
