## 1B. Task 1 产物：后端迁移触达矩阵

| 模块域 | 关键路径 | 影响级别 | 迁移动作 |
|---|---|---|---|
| API Layer | `app/api/aggregate.py`, `app/api/agents.py`, `app/api/realtime.py`, `app/api/schemas.py` | 高 | 去除对 provider 细节依赖，仅保留请求校验/响应封装与 DI 注入点 |
| Application Layer | `app/services/aggregate_service.py`, `app/services/instance_service.py`, `app/services/auth_service.py` | 高 | 重组为用例编排中心，统一调用 Domain Contract/Adapter 接口 |
| Domain Contract Layer | `app/domain/*.py` | 高 | 新增 provider 无关契约类型；冻结错误、freshness、diagnostics 语义 |
| Provider Adapter Layer | `app/adapters/`（新增实现）+ `app/services/openclaw_client.py`（被适配） | 高 | 增加 Adapter 抽象与 OpenClawAdapter；外部报文映射下沉到 Adapter |
| Infra Layer | `app/services/openclaw_client.py`, `app/db/session.py`, 配置读取点 | 中 | 保留客户端/重试/超时能力，但禁止泄漏到 API/Application |
| Persistence Layer | `app/db/models.py` + 相关 service 仓储访问 | 中 | 持久化接口稳定，避免 schema 语义漂移；必要时仅做最小兼容演进 |
| Tests | `tests/integration/*.py`, `tests/test_observer_realtime_state.py`, `tests/test_instance_*` | 高 | 更新测试桩与断言，验证新调用链与旧路径移除；保持 v0.6 外部契约断言不变 |

## 1C. Task 1 产物：本次迁移范围声明

### In-Scope
- 后端内部架构重组：API/Application/Domain Contract/Adapter/Infra/Persistence
- OpenClaw 直连路径迁移至 OpenClawAdapter
- 关键链路测试与验收门禁更新（不改变验收标准，仅更新实现映射）
- 迁移窗口内删除旧路径与死代码（breakly）

### Out-of-Scope
- 新增第六页面或改动五页 IA 角色定义
- 改动 session canonical 路由语义
- 改动对前端暴露的 v0.6 聚合字段语义
- 引入除 OpenClaw 之外的新 provider 业务能力（本次仅完成可扩展骨架）
- `settings/profile` 页面或长期规划项落地
