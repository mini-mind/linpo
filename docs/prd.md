# Linpo PRD

## 1. 产品定义

Linpo 是位于 OpenClaw 与用户之间的人机协作编排交互层。
OpenClaw 提供 Agent 执行能力，Linpo 提供流程编排、看板推进、审批与结果可视化。

## 2. 开源版目标（单实例）

开源版目标是打通以下闭环：

`一句话需求 -> 流程图（可编辑）-> DAG 任务队列 -> 看板推进 -> 审批 -> 结果预览/下载`

并且保持部署简单：

- 启动前仅需提供 `OPENCLAW_BASE_URL` 与 `OPENCLAW_GATEWAY_TOKEN`。
- 不要求用户在页面内配置实例或执行配对流程。

## 3. 路由与页面

保留主工作区：

- `/summary`
- `/kanban`
- `/flow/edit/:flow_id`
- `/instance-files`

移除开源版能力入口：

- 用户菜单中的实例管理与配对流程入口

## 4. 核心行为

1. 用户在流程页输入需求，系统生成可编辑流程。
2. 用户确认流程后入队执行。
3. 系统按依赖推进任务状态：`queued/running/blocked_by_approval/failed/completed`。
4. 用户在看板与摘要中处理审批、查看状态。
5. 用户在任务产出与文件页预览/下载成果。

## 5. In-Scope / Out-of-Scope

### In-Scope

- 流程规划与编辑
- DAG 任务调度
- 审批与状态推进
- 产出预览与下载
- 单实例 OpenClaw 对接（由启动配置提供）

### Out-of-Scope

- 多实例管理与切换
- 运行时配对会话、挂载/卸载回执流程
- 支付、会员充值、模板市场
- Tauri 客户端

## 6. 成功标准

- 按 README 部署可直接进入主链路，无需实例管理步骤。
- 主链路可闭环到可预览/可下载成果。
- 页面仅保留开源单实例必需能力，不包含多实例残留入口。
