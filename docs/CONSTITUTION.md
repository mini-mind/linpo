# RoBoard Constitution

**Last updated**: 2026-03-03

## Core Principles

1. **Agent-First**: Everything is an agent
2. **Template-Driven**: Agents come from templates
3. **Recruitment-Based**: Agents are recruited, not created
4. **No Backward Compat**: We break compatibility to move fast

## Governance

- Technical decisions: Lead engineer + team discussion
- Architecture changes: Design doc + team review
- Breaking changes: Deprecation notice + migration guide

## Documentation Standards

- AGENTS.md: Service-level documentation (20-40 lines)
- PRD: Product requirements (source of truth)
- Specs: API contracts (single source of truth)
- Handoff: Session continuity (dated filenames)

## Version Policy

- No semantic versioning
- Date-based tags (YYYYMMDD-shortsha)
- Breaking changes allowed with notice
