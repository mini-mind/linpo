# Linpo v0.5 用户模型与实例配置基础设计与实施记录

> **状态**：已完成，公网流程已验证通过（2026-03-18）。

**目标：** 为 Linpo 引入最小可用的用户认证、实例配置与实例归属能力，让“谁在使用系统、他拥有哪些 OpenClaw 实例”成为显式系统模型，为 v0.6 多实例聚合打基础。

**架构：** 后端在现有 FastAPI 基础上新增 auth 与 instances 两组 API，使用 PostgreSQL 持久化用户与实例配置，使用服务端 session cookie 维持登录态。前端沿用现有左侧导航结构，在拓扑页演进为“实例拓扑视图”，将实例作为节点展示，节点详情通过弹窗承载；账户入口放入侧边栏底部。

**技术栈：** FastAPI、PostgreSQL、SQLAlchemy/SQLModel 或现有 Python ORM、bcrypt/passlib、服务端 session cookie、React、React Router、TypeScript、Vitest、pytest

---

## 0. 已确认设计约束

- 登录方式：用户名 + 密码
- 数据库存储：PostgreSQL
- 实例保存前必须验证 endpoint 可连通性与 token 可用性
- 每个用户最多 3 个实例
- Gateway Token 后端加密存储
- 侧边栏底部账户区域只展示用户入口，不展示实例信息
- 拓扑页保持全局拓扑视野，实例以节点形式展示，详情通过弹窗展示
- 首期实例类型只支持 `openclaw`
- v0.5 不引入 OAuth、RBAC、软删除、找回密码、多组织/团队模型、微信登录、实例共享

```python
class User(Base):
    __tablename__ = "users"
    id = mapped_column(UUID, primary_key=True)
    username = mapped_column(String(64), unique=True, nullable=False)
    password_hash = mapped_column(Text, nullable=False)
    created_at = mapped_column(DateTime(timezone=True), nullable=False)

class Instance(Base):
    __tablename__ = "instances"
    id = mapped_column(UUID, primary_key=True)
    user_id = mapped_column(ForeignKey("users.id"), nullable=False)
    name = mapped_column(String(100), nullable=False)
    type = mapped_column(String(32), nullable=False, default="openclaw")
    endpoint = mapped_column(Text, nullable=False)
    gateway_token_enc = mapped_column(Text, nullable=False)
    status = mapped_column(String(32), nullable=False, default="inactive")
    last_check_at = mapped_column(DateTime(timezone=True), nullable=True)
    created_at = mapped_column(DateTime(timezone=True), nullable=False)
```

## 3. 实施边界与风险提醒

- 不要把实例 token 明文返回给前端；编辑实例时也不能回显旧 token。
- 不要让未登录用户访问 observer/chat 业务接口；未登录、越权、实例不存在都必须返回明确错误。
- 不要把“当前实例”塞到账户区，账户区只承载用户入口。
- 不要把拓扑页退化成普通实例列表页；必须保留全局节点视野。
- 不要在 v0.5 提前实现 v0.6 的多实例聚合能力。
- 不要跳过保存前验证；前端“测试连接成功”不能替代后端保存时再次验证。
- 当前阶段同时引入 PostgreSQL、认证与实例配置三类基础设施，必须严格控制范围，避免把未来能力混入 v0.5。

## 5. 验收结论

v0.5 已于 2026-03-18 完成公网流程验证，核心闭环如下：

**用户认证闭环：**
- 注册新用户 → 后端 session 持久化 → 登录成功跳转拓扑页
- 未登录访问受保护路由自动跳转登录页
- 侧边栏底部账户入口，点击展开菜单，菜单项为退出登录

**实例配置闭环：**
- 拓扑页空状态引导新建实例
- 实例表单填写 endpoint + gateway token（按 README claw1 配置验证通过）
- 后端验证连接成功后加密存储 token
- 拓扑页展示实例节点，点击打开详情弹窗

**实例上下文闭环：**
- 会话页直接进入或从拓扑页进入时，展示实例列表供用户选择
- 当前实例选中状态持久化（localStorage）
- 进入会话页时自动携带当前实例 ID
- 后端根据用户 + instanceId 解析实例配置构造数据源

**会话级设置语义：**
- 模型切换为会话级别设置，切换后仅影响当前会话，不影响其他会话

**运行前提：**
- PostgreSQL 数据库已初始化（users、instances、sessions 表）
- 前端 `http://175.178.213.10:5173`，后端 `http://175.178.213.10:8000`
- OpenClaw 实例需在对应端口运行并有有效 gateway token
