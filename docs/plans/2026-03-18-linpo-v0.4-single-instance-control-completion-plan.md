## 1. 文档目的

本文档定义 Linpo v0.4 的实施范围与计划：在 v0.3 最小控制闭环验证成功的基础上，完善单实例控制能力，补齐与 OpenClaw ControlUI 的功能差距。

v0.4 的核心目标是：

> 把 v0.3 的"最小控制验证"扩展为"完整单实例控制能力"，但仍保持单实例、受信环境、单操作者边界。

---

## 2. 版本定位

### 2.1 v0.3 已验证

- `chat.send`：发送消息
- `chat.abort`：暂停/中断
- Realtime 状态确认闭环

### 2.2 v0.4 目标

| 功能分类 | OpenClaw API | v0.4 目标 |
|---------|-------------|----------|
| 会话列表 | `sessions.list` | ✅ |
| 会话预览 | `sessions.preview` | ✅ |
| 会话配置 | `sessions.patch` | ✅ |
| 会话重置 | `sessions.reset` | ✅ |
| 会话删除 | `sessions.delete` | ✅ |
| 模型列表 | `models.list` | ✅ |
| 消息历史 | `chat.history` | ⚠️ 可选 |

### 2.3 v0.4 不做

- 多用户登录/授权
- 多实例控制/聚合
- 跨实例消息路由
- 文件系统视图
- 长期操作审计仓库

### 切片 4：控制状态完善

**范围**：完整状态流转与错误处理

**状态流转**：
```
sending → accepted → applied
    ↓         ↓        ↓
  failed   failed   failed
    ↓         ↓
  timeout  timeout
```

**v0.3 状态**：sending/accepted/failed
**v0.4 补齐**：applied、timeout、细分错误类型

**实现要点**：
1. `applied` 状态通过 realtime observer 流确认
   - 监听 `topology_updated` 或 `node_events_appended`
   - 匹配 correlation_hint 确认生效
2. 超时检测：发送请求后启动计时器（默认 30s）
3. 错误类型细分：

| 错误类型 | 说明 | UI 展示 |
|---------|------|--------|
| `pairing_required` | 设备未配对 | 显示配对引导 |
| `unauthorized` | 权限不足 | 显示权限说明 |
| `session_not_found` | 会话不存在 | 提示创建会话 |
| `agent_not_found` | Agent 不存在 | 提示检查配置 |
| `rate_limited` | 请求过快 | 显示冷却时间 |
| `internal_error` | 服务端错误 | 提供重试入口 |

**验收标准**：
- [ ] applied 状态通过 realtime 流确认
- [ ] 超时正确检测并显示
- [ ] 错误原因清晰展示
- [ ] 提供重试入口

```python
# app/api/schemas.py

class SessionListItem(BaseModel):
    key: str
    kind: str  # direct | group | global | unknown
    label: str | None = None
    derived_title: str | None = None
    last_message_preview: str | None = None
    updated_at: int | None = None

    ts: int
    count: int
    sessions: list[SessionListItem]
    defaults: dict[str, Any] | None = None

class SessionPreviewItem(BaseModel):
    role: str  # user | assistant | tool | system | other
    text: str

class SessionPreview(BaseModel):
    key: str
    status: str  # ok | empty | missing | error
    items: list[SessionPreviewItem]

class ModelItem(BaseModel):
    id: str
    name: str
    provider: str
    context_window: int | None = None
    reasoning: bool | None = None

class ModelsListResponse(BaseModel):
    models: list[ModelItem]

class SessionPatchRequest(BaseModel):
    model: str | None = None
    thinking_level: str | None = None
    fast_mode: bool | None = None

class SessionPatchResponse(BaseModel):
    ok: bool
    key: str
    resolved: dict[str, Any] | None = None
```

## 5. 前端实现规范

### 5.1 API 客户端扩展

```typescript
// frontend/src/api/client.ts

export async function listSessions(params: {
  agentId?: string;
  includeDerivedTitles?: boolean;
  includeLastMessage?: boolean;
}): Promise<SessionsListResponse> {
  const query = new URLSearchParams();
  if (params.agentId) query.set('agentId', params.agentId);
  query.set('includeDerivedTitles', String(params.includeDerivedTitles ?? true));
  query.set('includeLastMessage', String(params.includeLastMessage ?? true));
  query.set('dataSource', 'openclaw');
  const response = await fetch(`${API_BASE}/chat/sessions?${query}`);
  if (!response.ok) throw new Error('Failed to list sessions');
  return response.json();
}

export async function previewSessions(keys: string[]): Promise<SessionPreview[]> {
  const query = new URLSearchParams({ keys: keys.join(','), dataSource: 'openclaw' });
  const response = await fetch(`${API_BASE}/chat/sessions/preview?${query}`);
  if (!response.ok) throw new Error('Failed to preview sessions');
  const data = await response.json();
  return data.previews;
}

export async function patchSession(key: string, patch: SessionPatch): Promise<SessionPatchResponse> {
  const response = await fetch(`${API_BASE}/chat/sessions/${key}?dataSource=openclaw`, {
    method: 'PATCH',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(patch),
  });
  if (!response.ok) throw new Error('Failed to patch session');
  return response.json();
}

export async function resetSession(key: string): Promise<void> {
  await fetch(`${API_BASE}/chat/sessions/${key}/reset?dataSource=openclaw`, { method: 'POST' });
}

export async function deleteSession(key: string): Promise<void> {
  await fetch(`${API_BASE}/chat/sessions/${key}?dataSource=openclaw`, { method: 'DELETE' });
}

export async function listModels(): Promise<ModelItem[]> {
  const response = await fetch(`${API_BASE}/chat/models?dataSource=openclaw`);
  if (!response.ok) throw new Error('Failed to list models');
  const data = await response.json();
  return data.models;
}
```
