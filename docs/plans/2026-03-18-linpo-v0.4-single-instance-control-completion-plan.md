# Linpo v0.4 单实例控制完善计划

> **状态**：草案
>
> **目标版本**：v0.4
>
> **前置约束**：`docs/prd/2026-03-15-linpo-v0.1-observer-prd.md`、`docs/plans/2026-03-17-linpo-v0.3-single-agent-control-plan.md`

## 1. 文档目的

本文档定义 Linpo v0.4 的实施范围与计划：在 v0.3 最小控制闭环验证成功的基础上，完善单实例控制能力，补齐与 OpenClaw ControlUI 的功能差距。

v0.4 的核心目标是：

> 把 v0.3 的"最小控制验证"扩展为"完整单实例控制能力"，但仍保持单实例、受信环境、单操作者边界。

---

## 2. v0.4 版本定位

v0.3 验证了"控制协议可接入"和"控制闭环可观测"两个核心问题。v0.4 在此基础上：

1. **补齐控制操作全集**：完整实现 OpenClaw ControlUI 的核心控制能力
2. **完善状态反馈**：从"最小状态"扩展为"完整状态流转"
3. **增强错误处理**：提供重试、恢复、错误诊断能力
4. **提供管理入口**：Agent 绑定、会话管理等管理功能

v0.4 仍不做：

- 多用户登录/授权
- 多实例控制/聚合
- 跨实例消息路由
- 文件系统视图
- 长期操作审计仓库

## 4. 详细功能设计

### 4.1 A. 会话管理模块

#### 4.1.1 会话列表视图

**后端 API**：
```
GET /agents/{agent_id}/sessions?data_source=openclaw
```

**OpenClaw 调用**：
```json
{
  "method": "sessions.list",
  "params": { "agentId": "main", "limit": 50 }
}
```

**前端 UI**：
- 在工作空间页面新增"会话管理"标签页
- 显示会话列表：key、agentId、model、messageCount、updatedAt
- 支持按时间排序、按 agent 筛选

#### 4.1.2 会话历史预览

**后端 API**：
```
GET /agents/{agent_id}/sessions/{session_key}/preview?data_source=openclaw
```

**OpenClaw 调用**：
```json
{
  "method": "sessions.preview",
  "params": { "key": "user:alice", "limit": 20 }
}
```

**前端 UI**：
- 点击会话条目展开预览
- 显示最近 N 条消息（user/assistant 交替）
- 支持加载更多历史

#### 4.1.3 切换 agent/模型

**后端 API**：
```
PATCH /agents/{agent_id}/sessions/{session_key}?data_source=openclaw
Body: { "agentId": "coder", "model": "claude-opus-4" }
```

**OpenClaw 调用**：
```json
{
  "method": "sessions.patch",
  "params": { "key": "user:alice", "agentId": "coder", "model": "claude-opus-4" }
}
```

**前端 UI**：
- 会话详情中提供 agent/model 下拉选择
- 变更后实时生效

#### 4.1.4 重置/删除会话

**后端 API**：
```
POST /agents/{agent_id}/sessions/{session_key}/reset?data_source=openclaw
DELETE /agents/{agent_id}/sessions/{session_key}?data_source=openclaw
```

**前端 UI**：
- 会话操作按钮：重置、删除
- 删除需二次确认
- 操作后刷新列表

### 4.2 B. Agent 绑定管理

#### 4.2.1 绑定数据模型

OpenClaw agent 绑定包括：
- **Tools**：agent 可使用的工具列表
- **Resources**：agent 可访问的资源（文件、API 等）
- **Prompts**：agent 使用的提示词模板

#### 4.2.2 绑定查看 API

```
GET /agents/{agent_id}/bindings?data_source=openclaw
```

**响应结构**：
```json
{
  "agentId": "main",
  "tools": ["read", "write", "exec", "search"],
  "resources": [
    { "type": "file", "path": "/workspace" },
    { "type": "api", "endpoint": "https://api.example.com" }
  ],
  "prompts": ["system-prompt", "task-prompt"]
}
```

#### 4.2.3 绑定配置 API

```
PATCH /agents/{agent_id}/bindings?data_source=openclaw
Body: {
  "tools": { "add": ["mcp-tool-1"], "remove": ["exec"] },
  "resources": { "add": [{ "type": "file", "path": "/data" }] }
}
```

#### 4.2.4 前端 UI

- 在"配置编辑"标签页中新增"绑定管理"区块
- 工具列表：开关切换、添加/移除
- 资源列表：显示路径/端点、添加/移除
- 变更需要"应用"按钮确认

### 4.3 C. 控制状态完善

#### 4.3.1 状态流转

```
sending → accepted → applied
    ↓         ↓        ↓
  failed   failed   failed
    ↓         ↓
  timeout  timeout
```

**当前 v0.3**：只有 sending/accepted/failed
**v0.4 补齐**：applied、timeout、详细错误类型

#### 4.3.2 applied 状态确认

- `applied` 状态通过 realtime observer 流确认
- 监听 `topology_updated` 或 `node_events_appended`
- 匹配 correlation_hint 确认生效

#### 4.3.3 超时检测

- 发送请求后启动超时计时器（默认 30s）
- 超时后显示"超时"状态
- 提供"重试"按钮

#### 4.3.4 错误类型细分

| 错误类型 | 说明 | UI 展示 |
|---------|------|--------|
| `pairing_required` | 设备未配对 | 显示配对引导 |
| `unauthorized` | 权限不足 | 显示权限说明 |
| `session_not_found` | 会话不存在 | 提示创建会话 |
| `agent_not_found` | Agent 不存在 | 提示检查配置 |
| `rate_limited` | 请求过快 | 显示冷却时间 |
| `internal_error` | 服务端错误 | 提供重试入口 |

### 4.4 D. 错误处理增强

#### 4.4.1 网络断开重连

- 检测 WebSocket 断开
- 自动重连（指数退避）
- 重连后恢复未完成请求的状态

#### 4.4.2 请求失败重试

- 失败后显示"重试"按钮
- 可配置重试次数（默认 3 次）
- 重试间隔递增

#### 4.4.3 短期操作历史

- 最近 50 条控制请求记录
- 显示：时间、操作、状态、耗时
- 会话级存储，不持久化到数据库

## 6. 技术约束

### 6.1 保持单实例边界

- 所有 API 必须指定 `data_source=openclaw`
- 不引入多实例聚合逻辑
- 不引入用户隔离

### 6.2 复用 v0.3 基础设施

- operator 角色接入复用 v0.3 实现
- realtime observer 复用现有通道
- 错误处理复用现有框架

### 6.3 OpenClaw 协议约束

- sessions API 遵循 OpenClaw WebSocket 协议
- bindings 格式遵循 OpenClaw 配置规范
- 错误码映射 OpenClaw 错误类型

## 7. 风险与依赖

### 7.1 外部依赖

| 依赖 | 说明 | 风险 |
|-----|------|-----|
| OpenClaw sessions API | 会话管理功能 | ✅ 已稳定 |
| OpenClaw bindings API | 绑定管理功能 | ⚠️ 需确认协议 |
| OpenClaw operator 权限 | 控制操作权限 | ✅ v0.3 已验证 |

### 7.2 技术风险

| 风险 | 影响 | 缓解措施 |
|-----|------|---------|
| bindings API 变更 | 实现延迟 | 先确认协议再开发 |
| 会话数量过多 | 性能问题 | 分页加载、虚拟滚动 |
| 网络不稳定 | 用户体验 | 重连机制、离线提示 |
