# 灵盘 v0.1 产品需求

## 1. 产品定位

灵盘（Linpo）是一个面向复杂问题讨论场景的多 OpenClaw 编排产品。

当前 v0.1 的唯一目标不是构建通用多智能体平台，而是交付一个足够清晰、足够完整、足够可验证的最小闭环：

> 用户给出一个命题，系统组织多个 OpenClaw 实例围绕该命题进行结构化辩论，用户作为主持人/裁判介入，最终得到结构化总结与可回放记录。

## 2. 目标用户
- 需要快速比较不同方案的工程师 / 架构师
- 需要多视角论证的产品经理 / 研究人员
- 希望把“多个 AI 会话的手工协调”变成一个产品动作的用户

## 3. MVP 核心闭环

### 3.1 用户可以做的事
1. 创建一场辩论
2. 输入辩题
3. 指定或选择多个辩手角色
4. 观看多 OpenClaw 按回合展开辩论
5. 在辩论中插入主持人问题或调整方向
6. 主动结束辩论
7. 获取结构化总结并回看完整过程

### 3.2 MVP 必须成立的体验
- 创建辩论必须足够简单
- 多个辩手必须有清晰区分
- 用户干预必须即时、明确
- 输出总结必须可直接消费或复用
- 历史记录必须可回看

## 4. 非目标
当前 v0.1 明确不做：
- 通用 agent 组织树平台
- Blueprint 市场
- Browser automation
- 自建搜索能力
- 自建 llm-gateway
- 通用工作流引擎
- 多租户权限系统
- 大而全的平台管理后台

## 5. 产品演进方向
当前方向采用阶段式扩张：
- Phase 0：多 OpenClaw 辩论闭环
- Phase 1：多 OpenClaw 会话管理
- Phase 2：多 OpenClaw 编排
- Phase 3：Spawn agent 组织结构
- Phase 4：平台化治理与运营能力

## 6. 成功标准
灵盘 v0.1 的成功不是“平台能力很多”，而是以下闭环成立：
- 用户能在一次产品会话内完成从命题输入到总结输出
- 多个 OpenClaw 的回合编排可被用户理解与控制
- 结果具备复盘价值
- 架构与文档能支撑下一阶段继续扩张
